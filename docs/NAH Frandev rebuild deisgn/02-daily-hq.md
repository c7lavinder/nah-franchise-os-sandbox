# Daily HQ (dashboard)

Entry: Sidebar → Daily HQ. Reference: `New Again Houses App.dc.html` (Daily HQ).

Shell: Ask Scout bar (`Ask Scout anything...`).

1. **Unread pill** (orange) above KPIs: `1 unread`.
2. **KPI cards** (3): `34 New Prospects / last 30 days`, `62/250 Active Franchisees / of 250 goal`, `7/100 High Performers / 10+ purchased last 12mo`.
3. **Conversations area** — two-panel row:
   - **Left panel**: search (`Search conversations...`), tabs `All`(active) / `Unread 1` + refresh. Conversation rows: circular avatar (initials), name (bold), phone/number, right date; unread badge (blue count). Selected row highlighted.
   - **Right panel**: empty state (bot icon, `No conversation selected`, `Choose a conversation from the list`). When a conversation is selected → **thread view**: header (avatar, name, number, `● SMS · Signal House` status), message bubbles (outgoing = blue, right-aligned, timestamp above, `Delivered` below), composer (`+`, `Text Message` input, send button).
4. **Bottom strip** — 3 cards: **Work Queue** (`0 to clear`, `No queue items due right now.`), **Calendar** (`0 events`, `Thursday, July 9 · from GHL`, `No appointments today`), **Tasks** (`0 pending`, `No tasks`).

## Behavior

Clicking a conversation row opens its thread in the right panel. `All`/`Unread` filter the list.
