## Tabs: Ecosystem · Performance · Data · EOS

### Ecosystem

- Owner card: large avatar (initials), owner name, `OWNER`, `View profile`.
- Stakeholders table: columns Name/Company · Role · Phone · Email; rows with role pill; `+ Add stakeholder`.

### Performance

- Time filter: `Last Month / Last 3 Months / Last 12 Months / YTD (active) / All Time`.
- 9 metric cards: Leads Entered, Lead Progression, Lead → Purchase (avg days), Active Inventory, Purchased, Sold, Cycle Time, Avg Profit, Total Profit.
- Lead source chips: `17 Lists`, `8 Direct Seller`, `7 Referral Partners`.
- **Lead List Building**: donut chart + source legend (ProspectNow, etc.) + Benchmark Progression (`6 / 7,000 target`, `0%`). _(in prototype's L10-style donut; optional)_
- **Property Funnel** (YTD): 6 horizontal stage bars (Stage 1 → Stage 6 Purchase) with count + % + `x% from prior`; **Bottleneck board** callout (biggest pressure point + top 3 drop-offs).
- **Pipeline Comparison** table: Stage · THIS · MEDIAN · TARGET (median across active territories).
- **Latest Stage 4 Offers** + **Active Inventory** (per-property progress timeline: Purchased → Construction → Complete → Listed → Sold, with days-held, ARV, profit) + **Sold — YTD**. _(rich lists; build from real data — see prototype for row layout)_

### Data

Field-group accordions: Owner & Contact, Address, Business, Key Dates, Marketing, Compliance & Accounts, Territory Overview (`8/12 filled`), Demographics (`5/15 filled`). Full field lists from real data.

### EOS

- **Goals** matrix: rows (Gross Profit, Houses Purchased, Quality of Life) × columns (Actual, Current Year, Year 5, Year 25).
- **Scorecard**: Metric · Goal · Actual (e.g. T3 Leads Entered, T3 S1 to S4 %, T3 Purchased).
- **Business Habits** + **Construction EOS**: habit rows each with A–F grade cells (earned grade colored: A/B green, C amber, D orange, F red).
- **Rocks** (status pill `Off Track` + text), **Issues** (checklist), **To-Dos** (checklist; completed items struck through). Items may carry an `API` source badge.
